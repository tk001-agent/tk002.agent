# 面向 Agent 多模态认知体的记忆-心智建模方案

## 摘要

传统智能 Agent 大多聚焦于显性知识的存储与问答召回，仅依靠对话最终结论构建知识库，丢弃了交互过程中大量非结论类交互痕迹。本方案提出一套完整认知体架构：以完整原始交互素材为底层基座，分离客观知识归档层与元信号指针层，结合多模态输入扩展观测维度，支撑 Agent 逐步构建外部世界模型、用户心智模型以及 Agent 自我认知模型。方案强调原始证据不可篡改、元信号作为假说可回溯校验，避免将弱信号直接固化为客观事实，以此降低误解读风险，为高阶长期认知能力提供可落地的结构框架。

## 1 背景与问题

当前多数智能体的记忆机制存在固有短板：记忆完全依附会话上下文窗口，存在容量上限；交互历史随会话生命周期失效，早期交互素材被直接丢弃。知识加工通常在对话过程中即时完成，直接过滤掉所谓"噪声"片段，只保留整理后的结论要点。

该模式存在两个核心缺陷：

1. 加工与对话同步进行，一旦提炼、归纳出现偏差，不存在完整原始底本用于复盘、重新解析校正；
2. 将试探、纠结、联想跳转、表述中断、自我修正等交互片段视作无效垃圾直接丢弃。但这类片段并不承载客观命题，却携带思考路径、内在关注点、认知冲突等关键隐性信息，是构建心智认知的重要线索。

单纯文本交互的观测窗口十分狭窄，人类大量直觉、内心权衡、未言说的倾向不会完全转化为书面语言。仅依靠文本输出，很难完整刻画用户思考模式，也难以对 Agent 自身推理习惯、推理盲区形成有效自我观测。因此需要扩展至多模态维度，建立分层、可溯源的长期认知架构。

## 2 整体架构总览

整套体系分为四层，自底向上依次为：原始素材存储层、结构化知识归档层、元指针信号层、认知模型推理应用层。

核心设计原则：原始素材永久冻结不修改；结构化知识与元指针完全隔离；所有元信号均为可证伪假说，绑定原始素材溯源索引，不直接升格为客观事实。

1. **原始素材存储层**：完整留存全部交互原始数据，不做删减与改写。文本类包含输入语句、推理链路、工具调用记录、输出回复；多模态包含图像、手绘草图、语音、视频等原始文件，保留时序、坐标等元信息。原始素材是全部上层加工的唯一证据来源，所有整理、降噪、解析工作均为后置离线任务，不在原始数据上直接修改。
2. **结构化知识归档层**：基于原始素材离线加工生成，对应客观知识体系。采用层级话题树结构，从顶层知识域，向下拆分话题域、子话题、要点、原子事实叶子节点，分配稳定不变的节点编码。负责沉淀交互产出的结论、观点、事实、方法，形成可检索、可迭代更新的正式知识库；同时可基于同一套原始素材，衍生出平行的项目执行树等其他结构化视图。知识库更新遵循冲突消解规则，新信息覆盖旧内容时保留版本更替说明。配套轻量化常驻索引，用于快速定位节点，详细正文归档存储，按需调取。
3. **元指针信号层**：独立于客观知识树，不混入事实结论。专门收纳从交互中提取的各类"非噪声指针"。指针仅作为标记与索引，指向原始素材对应片段/时间戳/图像区域，本身不是事实。指针分为文本指针与多模态指针两类，单条指针不具备高可信度，依靠大量跨交互的统计共现，才形成有效观测信号。
4. **认知模型推理应用层**：推理阶段同时召回结构化知识与相关元指针集合。结构化知识用来回答事实、完成任务；元指针作为倾向性约束输入，用于迭代更新三套内部模型：外部世界模型、用户心智模型、Agent 自我认知模型，校正 Agent 的推理倾向与交互策略。

## 3 元指针信号层详细设计

### 3.1 文本维度指针

来源于文本交互过程中非结论片段：试探性提问、前后自我矛盾、主题无征兆跳转、表述中途中断、反复重复同一主题、不断改口修正。

信号含义：不代表真实客观结论，反映思考路径、内在关切点、认知冲突、联想链路。

### 3.2 多模态维度指针

多模态输入带来语言之外的观测维度，分为显性内容与行为指针。

- 显性内容：图片文字、手绘草图、视频口述观点，可以直接抽取并入结构化知识树；
- 行为元指针：语音停顿、语速波动、草图反复涂改的区域、视频神态肢体变化等。这类信号捕捉语言没有表达出来的直觉、内心纠结、注意力落点，极大拓宽对主体的观测边界。

### 3.3 指针约束规则

1. 指针库和客观知识树物理隔离，指针标签绝不直接写入事实节点，避免污染正式知识库；
2. 每一条指针必须携带溯源标记，绑定原始素材位置，支持随时回到原始记录复核、推翻旧假说；
3. 拒绝单样本下定结论，需要多次交互中稳定复现的信号，才提升参考权重；
4. 指针只作为推理的参考输入，不生成固定的条件-动作硬规则。

## 4 三套内部认知模型

整套架构最终服务于 Agent 维护三套并行模型：

1. **外部世界模型**：由结构化知识树的客观事实作为主体支撑，记录事物、因果、关系；
2. **用户心智模型**：不局限于记住用户知道哪些知识。借助元指针集合，建模用户的思考习惯、内在权衡、认知卡点、联想偏好、心理边界，理解用户"如何思考"，而不仅仅记住用户"说了什么"；
3. **Agent 自我认知模型**：解析 Agent 自身完整推理轨迹，收集推理分支、自我推翻、猜想失误等内部指针，识别自身容易出错的场景、推理惯性与认知盲区，实现一定程度的自我观测。

冰山隐喻：结构化知识树对应浮出水面可见的结论；元指针集合对应水面之下庞大的隐性线索集合，是心智模型构建的核心原料。

## 5 关键风险与应对方案

1. **弱信号过度解读风险**

   多模态以及文本指针全部属于弱信号，同一段行为可以存在多种解释。应对方案：坚持指针即假说，不把解读结果固化为事实；所有信号保留原始证据溯源，允许后续重新解析推翻原有判断。

2. **存储与算力成本**

   原始多模态素材存储会带来存储开销；知识库、指针库的语义召回会产生持续算力消耗。应对方案：原始素材与加工产物分层；常驻索引只保留轻量化摘要，完整详情归档存储，只在命中检索时加载，控制运行时资源占用。

3. **隐私安全风险**

   语音、图像、视频携带极高密度个人隐私信息。应对方案：原始交互素材独立归档，严格控制访问链路，区分公开输出与内部认知素材，原始底层数据不对外暴露。

## 6 工作执行流程

1. 交互发生，全部原始输入、推理、输出完整落盘保存，原始数据保持冻结；
2. 离线后置处理：一方面生成、迭代层级结构化话题知识树，维护稳定编码与双层索引；另一方面提取文本与多模态元指针，建立指针索引并绑定溯源位置；
3. 新交互到来时，通过索引召回相关知识节点与对应元指针集合；
4. 将知识用于任务应答，将元指针作为参考输入，迭代更新三套内部认知模型，调节推理与交互策略；
5. 持续积累交互样本，迭代知识库与指针库，完成版本收敛。

## 7 总结

该认知体方案跳出传统 Agent "只保存最终答案"的思路，把交互全过程痕迹当作核心资产。通过原始证据层-结构化知识-元指针-认知模型四层架构，区分客观事实与隐性观测线索，引入多模态拓展观测边界，实现 Agent 对客观世界、用户心智、自身推理的多层次建模。整套方案最大的特点是强调可溯源、可证伪，规避弱信号带来的误判问题，为实现具备长期演进认知能力的智能体提供一套结构化的设计思路。
